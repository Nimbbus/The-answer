The Answer 🎮
Overview
The Answer is an educational and narrative‑driven game developed in Unity. It combines engaging gameplay with meaningful themes, designed to encourage reflection and critical thinking among players. The project demonstrates how interactive media can be used as a tool for learning, awareness, and entertainment.

Features
🧠 Challenging Boss Fights: Includes the Rage Boss powered by a modular Behavior Tree AI.

🎨 Custom Visuals: UI sprites, animations, and effects to enhance immersion.

⚙️ Scalable Architecture: Built with design patterns for maintainable and extendable code.

🎯 Balanced Gameplay: Mechanics that support challenge, progression, and player motivation.

📚 Educational Impact: Narrative and mechanics that promote awareness and problem‑solving.

Technologies Used
Unity (URP, Shader Graph, NavMesh)

C# for gameplay scripting

GitHub for version control

Trello/MS Project for workflow management

Installation

1- Clone the repository:
git clone https://github.com/Nimbbus/The-answer.git

2- Open the project in Unity (recommended version: 2021.3 LTS or later).

3- Run the game from the Unity Editor or build for your target platform.
